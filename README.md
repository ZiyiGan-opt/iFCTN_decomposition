# iFCTN: Intra-Block Fully Connected Tensor Network Decomposition

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white)

Python implementation of **intra-block fully connected tensor network (iFCTN)** decomposition, with a demo for multispectral image completion.

iFCTN represents tensor factors through structured matrix factors to capture cross-mode correlations. The released demo reconstructs a three-way multispectral image from partially observed spectral fibers using alternating proximal updates. The implementation uses PyTorch and automatically selects a CUDA GPU when available, with CPU execution as a fallback.

---

## Installation

Clone the repository and enter the project directory:

```bash
git clone https://github.com/ZiyiGan-opt/iFCTN_decomposition.git
cd iFCTN_decomposition
```

Alternatively, select **Code → Download ZIP** on GitHub, extract the downloaded repository, and open the directory containing `main.py`.

Install the dependencies in your Python environment:

```bash
python -m pip install torch numpy scipy matplotlib scikit-image
```

For GPU execution, use a CUDA-enabled PyTorch installation compatible with your GPU driver. Installation options are available on the [PyTorch website](https://pytorch.org/get-started/locally/).

## Data

Three CAVE multispectral image samples are included in `data/`. Each sample is stored as a MATLAB `.mat` file containing a tensor of size **256 × 256 × 31**.

| Sample | File |
| --- | --- |
| Face | `data/cave_face_ms_256.mat` |
| Flower | `data/cave_flower_ms_256.mat` |
| Toy | `data/cave_toy_ms_256.mat` |

The demo normalizes the input by its maximum value. Missing observations are generated by randomly selecting spatial locations and removing all spectral bands at those locations; the same spatial mask is therefore shared across the 31 bands.

---

## Running the demo

Run the following command from the repository root (the directory containing `main.py`):

```bash
python main.py
```

By default, the demo loads the **Face** sample, removes **60% of the spectral fibers**, and reconstructs the missing values with iFCTN. Observed entries are preserved during reconstruction.

The script prints **PSNR, SSIM, RSE, and elapsed time** for the zero-filled observation and the iFCTN reconstruction. It also displays a side-by-side RGB visualization using spectral bands 29, 19, and 9.

PSNR and SSIM are averaged over all spectral bands. RSE is the Frobenius norm of the reconstruction error divided by the Frobenius norm of the reference tensor. Metrics are computed over the full tensor, including observed entries.

### Changing the settings

Edit the following settings in `main.py`:

```python
DATA_PATH = os.path.join("data", "cave_face_ms_256.mat")
MISSING_RATIO = 0.6
RHO = 0.1

# Inside main():
opts = {
    "tol": 1e-5,
    "maxit": 1000,
    "rho": RHO,
    "R": [6, 6, 6],
}
```

| Setting | Description |
| --- | --- |
| `DATA_PATH` | Path to the input multispectral image. |
| `MISSING_RATIO` | Fraction of spectral fibers to remove. |
| `rho` | Proximal parameter used in the alternating updates. |
| `R` | Rank parameters in the order `[R12, R13, R23]`. |
| `tol` | Stopping tolerance for the relative change between consecutive tensor iterates. |
| `maxit` | Maximum number of iterations. |

For example, change `DATA_PATH` to `data/cave_flower_ms_256.mat` or `data/cave_toy_ms_256.mat` to use another included sample.

## Code organization

The repository contains the following main files:

| Path | Description |
| --- | --- |
| `main.py` | Data loading, missing-mask generation, reconstruction, evaluation, and visualization. |
| `methods/ifctn_tc.py` | iFCTN tensor completion and batched subproblem solvers. |
| `methods/observed.py` | Zero-filled observation baseline. |
| `utils/data_loader.py` | MATLAB `.mat` data loading. |
| `utils/metrics.py` | PSNR, SSIM, and relative reconstruction error. |
| `utils/kr_kron.py` | Khatri–Rao and Kronecker product utilities. |
| `data/` | Three sample multispectral images. |
